# Try Carribrary’s temporary borrower demo

[Open the public test library](https://testlibrary.duckdns.org/s/L9PHAHbPWwiBki05Ad8ldyiY1ZN-AAUq/).

**This is a public test library. Use fictional names and contact details. Test data may be deleted or reset without notice.** Do not enter real borrower information, private reading notes or a password used on another service. Everyone with the link can browse the shared catalog. The catalog may include books contributed by volunteer testers; it is not a promise that books can actually be collected or delivered.

## Try the borrower experience

1. Open the link in your browser. You do not need to buy or install anything.
2. Browse and search the books. Try the collection, sorting and per-page controls.
3. Submit a borrowing request using fictional details. Treat requests and suggestions as tests, not real reservations or purchase commitments.
4. Optionally create a test account to try personal TBR and reading tracking. Account registration may need librarian approval. Follow the private-reading setup instructions if prompted. An account is not required for normal guest browsing and requests.
5. To try the borrower PWA, use Account → This device and follow the installation instructions. On iPhone, use Safari → Share → Add to Home Screen. Browser/device installation options vary.

Only functions enabled by the test library are available. This is a borrower test, not public administrator access. The volunteer-hosted server may be offline occasionally. There is no uptime guarantee, permanent account or permanent storage promise.

## Report what happened

Use [Discussions](https://github.com/MadZombie83/Carribrary/discussions) for questions and general feedback, or [Issues](https://github.com/MadZombie83/Carribrary/issues/new/choose) for a reproducible bug. Include your device, operating system, browser and the steps you tried, plus the expected and actual result. Screenshots should hide account details and private links.

Do not post passwords, pairing codes, private connection files, backups, API/SMTP/DuckDNS keys or real personal information. Public support: **chezburbermerch@gmail.com**. Suspected security problems belong in the [private reporting process](SECURITY.md).

## Administrator testing

Administrator trials are arranged individually with approved testers. Contact the maintainer through Discussions or the public support address to ask about participating. Access is not automatic. Administrator pairing links remain private, and devices can be revoked after testing.

A future public administrator sandbox would need restricted permissions and a reset process. It is not offered by this borrower link. Testers should not use a private or real household library for unrestricted public administrator testing.
