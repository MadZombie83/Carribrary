# Report a security concern privately

Email **chezburbermerch@gmail.com** with the subject **Carribrary security report**.

Describe the affected version, the problem and safe reproduction steps using fictional data. Please do not post a public issue containing exploit details, live credentials, private library links, borrower data or backups. Never send private signing keys or passwords.

Chezburber Studios will review reports as available. No response-time guarantee or paid bounty program is offered. The current preview is 2.0.53-preview; older previews are historical testing builds, not maintained release lines.

If a credential was exposed, revoke or rotate it using the relevant service and remove the public post. Deleting the post does not invalidate a credential or erase copies others may have made.
