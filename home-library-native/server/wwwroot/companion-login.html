Carribrary

iPhone librarian companion

In Safari, tap Share → Add to Home Screen. Open that icon, then pair below. Android users can keep using the native companion.

Ask a household admin to open iPhone companion on the library server and create a single-use code. The code expires in 10 minutes. Pairing grants full administration for 30 days.

Help

Use the library’s HTTPS address. The server must stay on. This is for librarians; borrowers use the shared library QR. Never post a pairing code publicly. Revoke lost devices from iPhone companion on the server. If you install after pairing and need to pair again, create a fresh code and paste it in the Home-screen app.
