Help with local administrator access

Need another administrator? An existing administrator opens All tools → Dashboard accounts → Add administrator. Each person has a separate password, recovery code and local session. Borrower accounts do not grant dashboard access. All dashboard administrators have full library-administration permissions.

This login protects the dashboard on this computer. Already paired Android and iPhone/browser companions continue to connect without an extra password screen.

For first setup, open the private local-admin-setup.txt file in Carribrary's server data folder. The screen shows its location when setup is needed. On Windows, use Start → Carribrary → Administrator access and approve the administrator prompt to copy the code. The helper reads the private file without resetting credentials or signing you in. Never post its contents or send it to support.

If you lost your recovery code, stop the server, then use its HomeLibrary.Server executable with --prepare-local-admin-recovery and the same data-folder configuration. This writes a new private one-time setup/recovery file without erasing your library or phone pairing. Restart and choose Recover local administrator access. This advanced fallback requires access to the server's protected data. A previously approved companion can also prepare a code through the protected setup-code operation.

Local sessions expire after 30 minutes idle or eight hours total, and on server restart. Signing out ends only this local session. Public borrower accounts and private reading passphrases are separate.
