CARRIBRARY · INDEPENDENT RECOVERY

Bring your library back safely.

Verify a complete backup, try a separate recovered library, then restore only when you are ready.

Opening this private recovery session…

1. Choose and verify

Choose a .carribrary-backup file and enter its backup password. This local tool does not need a working dashboard. It never sends your archive to a cloud service.

Allow disk space for the upload, decrypted files, a test copy and the entire current data folder retained during restoration. Up to 2 GB of backed-up data / 10,000 files. The password cannot be reset.

2. Test a recovered copy

The test uses separate local ports and a disposable data copy. Email, push reminders and phone discovery are disabled, and its phone listener stays on this computer. Your working library remains unchanged.

Open the test link in an InPrivate / Incognito window. Sign in using the administrator credentials in the backup and inspect books, borrowers and loans. Borrower vaults still need each borrower's private passphrase or recovery code.

3. Restore the working library

This replaces current records with the older snapshot. Later loans, passwords, account deletions and device revocations are rewound. Legacy Windows-protected keys require the original computer. A successful test does not prove a replacement computer can decrypt them.

The current data folder is retained privately before replacement. Remote access is held locally after restore until an authenticated local administrator reviews accounts/devices. Current program files, service definitions, router/Caddy certificates and connection settings are kept; archive configuration files are retained for separate review. Recovered email and push settings are paused until you review accounts/devices and configure notifications again.

Flatpak: first use Stop the working library, sign in and confirm shutdown. This preserves the normal administrator check. The wizard will refuse replacement while the desktop server is still running.

Review restored access before going online

Open the restored local dashboard. Sign in, check accounts and paired devices, then choose Record local review in its restored-library banner. Return here afterward. Flatpak users must again confirm Stop on the local dashboard before restarting.

Interrupted restore

A previous restore did not complete. Keep all retained folders. Undo attempts to put the pre-restore data back and checks startup. No folder is deleted. If undo fails, keep the server offline and ask for help.

Finish and keep your backup safe

The original archive is never modified. Closing the browser tab alone does not stop this helper; use Finish below. Retained pre-restore or failed data folders remain private and are not removed by Finish. They can contain historical accounts and credentials.

Recovery limitations and retained folders

Automatic undo is attempted after a failed post-replacement startup check. A power loss or failed undo can require reopening this tool. Keep the journal and retained folders; never merge individual databases. Complete Backup Recovery restores data, not an operating-system image or older program files. Program-only rollback remains the separate Update and recovery tool. Closing the helper normally removes its temporary upload/test data; a crash can leave protected temporary folders for support to clean up.
