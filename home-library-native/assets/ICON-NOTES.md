# Carribrary app icon
Generated with the built-in image generation tool, then exported with Pillow into ICO and Android density resources. Both platforms use the same book/house/bookmark design. Android uses the second composition within the adaptive-icon safe zone.

Initial prompt: Square full-bleed opaque purple-to-blue app icon. Center an ivory open book whose outline forms a house roof, with a blue bookmark. Bold welcoming geometric shapes, legible at small sizes. No lettering, text, border, rounded outer corners, extra objects or watermark.

Edit prompt: Preserve exactly the artwork and palette; reduce the centered symbol to at most 54% width and 50% height, extending the existing gradient around it, for Android adaptive-icon safe cropping.

Files: home-library.png (master), home-library-adaptive.png (safe composition), home-library.ico (16 through 256 pixel Windows sizes).

Final built-in tool prompt (verbatim):
Keep exactly this ivory open book, house roof, blue bookmark artwork and purple-to-blue full-bleed background. Change only composition: reduce the centered book/house symbol to occupy at most 54% of the square width and 50% of height, centered both horizontally and vertically. Extend the existing gradient naturally around it. Production Android adaptive icon safe zone: generous empty gradient space around all four sides, all foreground symbol within centered 54% square. No text, no rounded outer corners, no extra elements. Square opaque image.
