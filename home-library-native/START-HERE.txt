CARRIBRARY — 2.0.48 PREVIEW

This is source. Follow BUILD-LOCALLY.md or run the included local builder to create
packages. Build into a separate Carribrary-2.0.48 folder; do not merge source with
an older build directory. No signing keys or library data belong in the source.

Before updating, create a complete password-encrypted backup and download a copy
off the server. Library JSON exports are not complete account/key/vault backups.
Update the server first, then companions, retaining existing application data.
Library format upgrades to 6, credentials remain 2. Older server programs cannot
open the new reading history safely. Program-only rollback supports 2.0.47–2.0.48;
guided complete restoration is a separate operation.

Windows: run your newly built installer over the existing installation. Do not
uninstall or delete app data. Open Carribrary from the desktop or Start menu.
Each administrator signs into the local dashboard with Carribrary credentials.
Paired remote devices continue using their approved tokens without extra login.

Android: install your newly built APK over the existing app, preserving app data
and signing identity. Only the APK goes on the phone; never copy private signing
folders there. New phones pair from the server's private administrator-phone QR.

iPhone: open your server's HTTPS /companion/ address in Safari, pair using the
private browser-companion code, then Share > Add to Home Screen. This is the
hosted PWA. Native Swift source still requires a Mac/Xcode for validation.

Linux: open your newly built Flatpak bundle in the software manager and update.
Raspberry Pi 4/5, 64-bit Raspberry Pi OS: install the newly built ARM64 DEB.
See linux/README.md. Keep existing package identities and data paths.

Settings & Tools → Library & Appearance has two pages: Library identity and
Theme & artwork. Presets clear artwork; saved themes restore their own PNG.
Settings & Tools → Data & History → Portable replacement backup optionally makes
a complete backup every seven days, retains four managed verified copies and
lets you download the latest. Copies on the same drive do not protect drive loss.
Routine catalog snapshots keep sixteen scheduled and seven daily files; manual
and migration safety copies remain separate.

On a replacement computer install Carribrary 2.0.48, launch Complete Backup
Recovery from the server application menu, verify the portable archive, rehearse,
confirm restoration and complete local access review. Configure the replacement
computer's router/DuckDNS/Caddy connection separately. Stop the old server before
bringing its restored identity online. Older Windows machine-bound archives still
need their original machine. Keep backup passwords and borrower vault recovery
codes safe: they cannot be reset by the developer.

Reading Tracker adds page progress, earlier rereading sessions, goals/statistics
and favorite quotes/page notes. Borrower-owned entries stay in the encrypted
personal vault; household profiles remain administrator-managed. Optional
anonymous aggregate library analytics is under Settings & Tools → Data & History → Analytics & insights and is
off until enabled. It never contains private reading data or search phrases.

See current Help, distribution/RELEASE-2.0.48.md and INSTALLER-GUIDE.txt. Device
installation, scanner, Safari, Flatpak portal and actual Windows machine-recovery
tests remain necessary before public distribution.
