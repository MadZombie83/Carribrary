# Carribrary 2.0.46 — artwork belongs to each saved theme

New theme in Library & Appearance → Custom theme editor clears the draft name and artwork preview instead of copying the last library overlay. The current colors remain a starting point. Select a saved theme to load its colors, name and own saved PNG or explicit no-artwork choice. Use current library artwork deliberately copies the active overlay into a draft. Save & use theme stores both colors and that artwork choice. Editing or cancelling a draft alone does not change the live library or overwrite saved themes.

Android Colors & custom themes uses the same empty-artwork New theme reset. Selecting a named theme loads its draft as well as changing local phone colors. Publishing a theme to the server continues to apply its own saved artwork. The hosted iPhone PWA uses the same corrected web editor. Existing custom themes, builtin presets, permissions and borrower data are retained.

Library/credential formats stay 5/2; no data migration. Compatible program-only recovery supports 2.0.45–2.0.46, and the guided full-data recovery accepts those format-5 sources plus supported43/44 format-4 sources. Older programs cannot read format5.
