# Carribrary 2.0.39 — dashboard pages and Settings & Tools

The primary sidebar keeps Dashboard, Catalog, Borrowers, Lending, Requests and Reading tracker, followed by one Settings & Tools entry. Its six category pages have their own navigable URLs, search, breadcrumbs, cards, saved-value/status labels and in-page editors. Browser Back/Forward and direct settings links work. Colors and saved themes are under Library & Appearance, not Catalog. Book sharing and collection management move to Books & Organization. Daily catalog filters, lending and dashboard shortcuts remain direct.

See [the administration inventory](ADMIN-TOOLS-INVENTORY-2.0.39.md): all existing tools and nested operations retain their existing handlers, server authorization, pairing, history and confirmation safeguards. Destructive data actions have a separate care section. Restoring a file or downloading CSV requires an explicit action; opening its route does neither. Protected backup preparation blocks navigation. Header connection status remains visible after retiring the old utility footer.

Catalog and Borrowers gain explicit headings, coherent controls and cards. Lending and Requests keep their operational flows in wider themed workspaces; Requests adds actual status counts, search and persistent filters across decisions. Settings-category editors render within their own page without a modal backdrop. The same components and palette tokens serve every library; no private branding is hardcoded.

Library titles fit whole words beside the logo, shrinking only to a readable 1-rem minimum. If necessary, the logo stacks above the title. Extremely long unbroken names scroll inside their label. User-uploaded sidebar artwork fills the whole sidebar beneath interactive controls and a dark contrast scrim. Preferred PNG canvas: 512 × 1536 pixels, input under 10 MB/8192 pixels per side, saved PNG up to 2 MB. Existing 512 × 256 artwork stays accepted but may crop; upload a portrait original for best results. No illustration is installed by default.

Source version: 2.0.39-preview; Android metadata 20039, with synchronized Help and unchanged native navigation. Hosted iPhone/browser companions receive the new web pages from the updated server; no new pairing or username screen is required. Native iPhone source metadata is 0.1.23/build 24, not verified with Xcode. Source archive extracts into Carribrary-2.0.39; GitHub's standard main-branch ZIP name remains Carribrary-main.

Back up before installing locally built packages. Library and credential version numbers remain 3/2, with no data rewrite. Earlier executables reject portrait artwork dimensions, so Windows program-only recovery is restricted to 2.0.39; private historical recovery points remain separate. No installers, APKs, AABs, Flatpaks or Pi DEBs were built or installed. Live library data and the owner's active build folder were untouched.
