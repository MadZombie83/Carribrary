# 2.0.53 administration inventory

New: Public sharing setup in Settings & Tools → System & Advanced, also linked from Setup & updates and Linux application menus. Local administrator only; paired-browser/Android networking changes denied. Windows page points to existing Connection setup.

All existing tools remain at2.0.51 locations. Library sharing still separately enables/revokes private catalog tokens. Existing Caddy, native Android pairing/install options, borrower Account installation, recovery safeguards and account privacy are unchanged.

## Optional self-service additions

| Tool | Browser/server route | Android route |
|---|---|---|
| Independent self-checkout, self-return and kiosk settings | Settings & Tools → Borrowing & Reminders → Borrower self-service & kiosks | Same category, same tool |
| Provision/revoke stations | Inside Borrower self-service & kiosks | Same tool |
| Issue, replace, revoke, restore-review, PIN reset and print cards | People & Access → Library cards; shortcut on each borrower | People & Access → Library cards / PINs; shortcut in Borrowers |
| Librarian scan or manually resolve a card | Normal Check out → Scan library card / Find card borrower | Normal checkout → Scan library card; manual borrower selection remains |
| Final physical receipt | Active-loan card → Confirm physical receipt / existing Return; notification bell links to active loans | On loan pending status; normal Return |
| Borrower phone self-service | Existing signed-in Catalog toolbar, when independently enabled | Borrower uses browser/PWA; native Android remains librarian companion |
| Digital issued card | Account | Same borrower browser/PWA |
| Restricted kiosk | Public trusted HTTPS /kiosk/ page, one authorized station | Browser computer; no second server |

No existing administrative function was removed. Existing saved settings, accounts, pairings, private-reading controls and recovery tools retain their routes.
