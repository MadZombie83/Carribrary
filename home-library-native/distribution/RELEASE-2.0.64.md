# Carribrary 2.0.64-preview source

Android batch camera scanning keeps Close in a fixed toolbar and bounds its
CameraX preview using compatible texture rendering. Landscape uses side-by-side
preview and controls. The live callback uses current Compose state.

The optional Look up new ISBNs automatically switch is available in batch
entry and continuous camera scanning. It defaults on and remembers the choice
on the phone. It controls new rows. Existing pending lookups may finish.
Manual lookup retry and review-before-save remain available.

Android's batch ISBN field accepts Enter from a Bluetooth/USB keyboard scanner.
Use keyboard/HID mode, EAN-13 support, and an Enter suffix. Specific hardware
compatibility and the physical camera fix require owner testing.
