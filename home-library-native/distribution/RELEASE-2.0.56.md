# Carribrary 2.0.56 preview — compact artwork editor

The Theme & artwork header editor now has Portrait and Landscape buttons and a compact control panel beside the active live preview. Percentage badges stay beside their labels as a single value such as 50%. On narrow screens, the preview sits above the controls and remains visible while scrolling through them.

Switching orientations preserves unsaved changes. Fitting, focus, overlay, saved themes, uploaded images and server validation are unchanged. Changes remain private drafts until Save & use theme. Help describes the new arrangement.

This is a source iteration. Rebuild packages to receive the change; existing 2.0.55 release installers are unchanged. No installer or APK was produced in this workspace.
