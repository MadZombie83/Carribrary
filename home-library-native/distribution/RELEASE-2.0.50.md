# Carribrary 2.0.50 preview — purchase suggestions and optional accounts

Anyone with the enabled shared library link can suggest a book or series for the library to acquire, without an account. The form asks for a title and optional author, valid ISBN and short reason. Series do not need an ISBN. An approved account can use the same action beside Catalog filters while its encrypted personal list remains locked.

Admins review Reader purchase suggestions inside the existing Books to buy tool, including native Android and the iPhone/browser companion. Keep for consideration, Decline and confirmed Delete affect only the suggestion; they do not purchase, reserve, add an owned copy or change the private acquisition wishlist. Pending suggestions appear in the admin bell and optional request alerts. Suggestions have no name/contact fields or account association; their text is visible only to administrators and encrypted at rest in a separate SQLite file. Avoid personal/contact details in free text. Ask the librarian to remove a suggestion; account deletion cannot identify anonymous suggestions.

The shared catalog, sign-in and registration screens explain that accounts are completely optional and free. Guests can browse, request to borrow and suggest purchases. Accounts add personal TBR, reading tracking/history and loan/request management after librarian approval. Sign-in/registration reached from a shared link offer Continue without an account. Personal reading remains in the existing encrypted private-list system, separate from operational suggestions.

Public submissions use the existing origin checks and request rate limits. Request IDs prevent duplicate retries, including delayed retries after deletion while a receipt is retained. Live suggestions are bounded at500; hashed retry receipts at2000 plus any live IDs. Stale admin decisions conflict instead of overwriting a newer decision. The public cannot enumerate suggestions. A revoked sharing link cannot submit; an approved account remains separately authorized. Complete backups include the protected suggestion database; library-only JSON exports do not. Historical complete restoration rewinds that inbox like other server data.
