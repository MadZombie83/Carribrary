# Carribrary 2.0.38 — Android design and saved themes

The Android companion keeps existing pairing and lending behavior while improving the banner, line-icon navigation, library counts and catalog cards. Everyday Add book / Check out / Return actions follow search. Filter & sort contains collection controls and bulk editing. Each book retains its primary lending action and About; Edit, Receipt and Recycle Bin are under Book options. Existing confirmations and permissions remain.

Web and Android custom theme editors provide eight semantic color roles, full spectrum color controls plus hex values, a preview, named save/edit/reselect and 4.5:1 text-contrast validation. Custom themes save on the authoritative server and are included in backups. Switching presets preserves saved palettes. Android presets and saved selections remain phone preferences; saving a custom theme activates it on the server. Use my colors for shared library explicitly publishes a selected phone preset.

The active server palette reaches the borrower catalog/account pages, local administrator login and recovery/setup states, server help and iPhone browser/PWA sign-in/help. Unauthenticated branding responses contain only library name, selected palette and the already-public icon; administrative APIs still require approved credentials. Google attribution images remain unchanged.

Native Android compilation is verified; device rendering, camera, Windows/Pi installation and native iPhone execution are not claimed. Further dashboard page design and mobile visual polish remain on the roadmap.
