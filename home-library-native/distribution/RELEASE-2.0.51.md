# Carribrary 2.0.51 preview

The public root welcome page no longer loads the borrower install script or shows its install button/status block. Theme, artwork, navigation and responsive layout remain. Account → This device and shared-catalog installation remain, as do librarian PWA controls and native Android installation options.

Saved theme artwork decorates borrower catalog/account/reading headers, companion pairing and librarian PWA banners, and Android’s library banner. Images are decorative, cropped and tinted; cards remain clear. A plain theme clears previous artwork, while saved themes restore their own PNG. Browser branding uses a versioned same-origin public PNG endpoint; artwork is public branding, with no catalog token exposed.

Build the server packages and Android APK from this source; refresh browser PWAs after updating the server. No EXE, APK, DEB or Flatpak release packages were built. Library/credential formats remain6/2; recovery supports47–51. Existing accounts, data, pairing and navigation are unchanged.

Validation: disposable desktop/mobile browser fixtures cover root removal, artwork loading, saved-theme switching and Account install fallback. Existing PWA/account/theme suites, .NET and Kotlin checks are recorded with source delivery. Actual Android/iPhone devices still need owner smoke testing.
