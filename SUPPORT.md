# Carribrary support

Carribrary Server is free to use and is currently a public preview. Support is provided by Chezburber Studios as available; there is no guaranteed response time.

## Get started

1. Download the installer for your computer from the [current preview releases](https://github.com/MadZombie83/Carribrary/releases).
2. Follow the [installation guide](home-library-native/INSTALLER-GUIDE.txt). Most people do not need to download or build source code.
3. Open Help in Carribrary for step-by-step setup and everyday tasks. The [current help guide](Carribrary-Help-2.0.59.md) is also available here.
4. Before updating or testing recovery, create and verify a complete backup and keep a copy on another device.

## Ask a question

Use [GitHub Discussions](https://github.com/MadZombie83/Carribrary/discussions) for installation, setup, troubleshooting and feedback. Mention your Carribrary version, operating system, installer type and what you are trying to do. A GitHub account is needed to post.

If you cannot use GitHub, email **chezburbermerch@gmail.com**. Do not email passwords, keys, full backups or borrower records.

## Report a bug

1. Check [existing issues](https://github.com/MadZombie83/Carribrary/issues) for the same problem.
2. Choose [Bug report](https://github.com/MadZombie83/Carribrary/issues/new/choose).
3. Describe the steps, expected result and actual result. Include the version and device/operating system.
4. Share only a short, redacted error excerpt or screenshot. Check screenshots and browser address bars for private information before posting.

Never post passwords, API keys, SMTP or DuckDNS tokens, pairing codes, private library/card links, borrower names/contact information, reading records, databases, complete backups or signing files. Public posts can be copied even after deletion. Keep your original logs privately; we can ask for a safe excerpt if needed.

Suspected security vulnerabilities should be [reported privately](SECURITY.md), not as public issues.

## Android availability

The optional paid Android librarian companion is planned for Google Play after testing. There is no public APK or AAB download here. Borrowers do not need to buy the companion; they use the library's free browser/PWA link.
